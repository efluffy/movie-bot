  Moviebot Help
-----------------
This bot will maintain a list of movies that people add along with votes. Every week, the bot will automatically:
- Remove any movies with 0 votes from the previous week
- Add a random movie from IMDB's top 100 list with 0 votes

The community can vote on movies, and those with votes will be kept in the list for future selection.

Commands:

!add - For adding a movie to the list. 
	usage: "!add <movie title>"

!rem - Allows you to remove a movie from the list.
	usage: "!rem <movie id>"
	
!vote - Allows voting on a specific movie.
	usage: "!vote <movie id>"

!list - Returns a list of currently saved movies, votes, and IDs.
	usage: "!list"

!select - Manually trigger the weekly movie update process.
	usage: "!select"
